# Монгол хэлээрх анагааны контент — дүрэм

Энэ директор нь Human Atlas загварын **бүх монгол контентын** нэг цорын ганц эх сурвалж юм.

## 1. Зарчим

1. **Үндсэн нэр** латин эсвэл гадаад хэвээр үлдэнэ: `Os femoris`, `Cor`, `Pulmo dexter`, `Vena portae hepatis`.
2. **Тайлбар** үргэлж монгол хэлээр, 3–5 өгүүлбэртэй:
   - 1-р өгүүлбэр: байрлал, хэлбэр, хэмжээ (тоо зөв бол).
   - 2–4-р өгүүлбэр: үүрэг, бүтэц, холбоо.
   - сүүлийн өгүүлбэр: клиник эсвэл функционал ач холбогдол.
3. **Анагааны үнэн зүйл** бүрэн зөв байх ёстой. Тоо, хэмжээ, харьцаа зөвхөн баталгаатай үед л бичигдэнэ; эргэлзээтэй бол бичихгүй эсвэл ерөнхий хэлбэрээр ("хэдэн сантиметр") бичнэ.
4. Латин нэр томьёог зөвхөн **толгой дээр** лавлана: нэг бүртгэлд хамгийн ихдээ 3–4 удаа.

## 3. Олон улсын стандарт нэр томьёо (Terminologia Anatomica)

Анагаадын бүтцийг орчуулахдаа **латин нэршил** тулгуур болно: эх сурвалжийн англи нэрийг
дур мэдэнхүй орчуулж болохгүй; эхлээд түүний олон улсын латин нэршилийг тогтоод,
дараа нь монгол анагаахын хэллэгтэй цав тааргана.

### 3.1 Чиглэл, байрлалын нэршил

| Латин | Монгол | Тайлбар |
| --- | --- | --- |
| Superior / Inferior | дээд / доод | биеийн тэнхлэгийн дагуу |
| Anterior / Posterior | өмнөд / хойд | үргэлжлэл |
| Proximal / Distal | төвөөс дотор / төвөөс хол | биеийн төвийн талаас |
| Medial / Lateral | дотор / гадна | голын шугамын талаас |
| Cranial / Caudal | дээд / доод | гэрийн суурь руу |

### 3.2 Хөдөлгөөний нэршил

| Латин | Монгол |
| --- | --- |
| Flexion | махийлгах, эвхэх |
| Extension | тэнийлгэх |
| Abduction | алслуулах |
| Adduction | ойртуулах |
| Pronation | пронаци (дотор эргүүлэх) |
| Supination | супинаци (гадна эргүүлэх) |

### 3.3 Латин нэрийг бичих дүрэм

Монгол нэр **эхлээд**, дараа нь латин нэр томьёо хаалтад бичигдэнэ:
`Дундаж яс (Os femoris)`, `Холбоос (Ligamentum cruciatum genus anterius)`.
Бүртгэл бүрд хамгийн ихдээ 3–4 удаа лавлана.

### 3.4 Тайлбарын бүтэц

1. **Байршил ба бүтэц** — ямар эрхт, хаана байрлаж, ямар бүтэгтэй.
2. **Иннерваци ба эх сурвалж** — ямар нерв, ямар артери, сув хангана.
3. **Үүрэг функц** — ямар үүргийг гүйцэтгэнэ.
4. **Клиник ач холбогдол** — гэмтэл, эмгэг, хэмжилтийн онцгой зүйл.

### 3.5 Эх сурвалж

АШУҮИС-ийн анагаах ухааны анатомийн сурах бичигүүд (Ж. Амарсанаа, Д. Амгаланбаатар
нарын «Хүний анатоми»), Латин-Англи-Монгол анатомийн толь бичиг, E-Health / МОНФАБ-ийн
нэр томьёоны мэдээллийн сан зэрэгт хэрэглэнэ.

## 4. Хэл найралын дүрэм

- Өгүүлбэр бүр дуусвал **цэг** тавьна; жараалсан үгсийн тогтмол цэг, үсгийн томьёо зөв хэрэглэнэ.
- Хоёр үг давхцахгүй ("эмгэг, ... эмгэг"), үг давхардсан бол дахин бичнэ.
- **Англи үг үлдэхгүй** (латин нэр томьёоноос бусад). "ventricle", "chordae", "dural" гэсэн зүйл зөвхөн латин хэлбэрээр, хаалттай бичигдэнэ.
- Тоон завсар: `1600–2000` (тире), `1.5–2 килограмм`; "аас" хэмээсээ хэрэглэхгүй (`1.4–1.6 килограмм`, **биш** `1.4-аас 1.6`).
- Загвар үгсийн эрэмбэ: эхний өгүүлбэр тодорхойлолт, дараагийн нь үүрэг, сүүлийнх нь ач холбогдол.
- Тогтмол үг хэрэглэ: `байрлах`, `үүрэгтэй`, `холбоотой`, `гүйцэтгэнэ`, `зохицуулна`, `хамгаална`, `үйлчилнэ`.
- «... юм» хэлбэрийг тодорхойлолтын өгүүлбэрт, «... байна» хэлбэрийг байдлын өгүүлбэрт ашиглана.
